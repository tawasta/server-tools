===========================================================
Auth Signup Verify Email: 'Reset Password' Button Text Fix"
===========================================================

* Fix the poor wording on the password reset page when reached via email
* Changes the wording from Reset Password to Set Password, as the user
  is only creating their account at that point, and especially the 
  i18n translations of the the original term could be way off of what
  is actually happening (e.g. Finnish "Unohtunut salasana") 

Configuration
=============
* None needed

Usage
=====
* Register as user and follow the registration link in the
  related email. The new terminology is used.
