=========================================================
Directly change user's Default company from dropdown menu
=========================================================

* Extend the functionality of company dropdown widget to also
  change company_id value for user

Configuration
=============
* None needed

Usage
=====
* In multicompany environment, select a company from top bar as usual.
  Now this also changes the default company (company_id field) value.
