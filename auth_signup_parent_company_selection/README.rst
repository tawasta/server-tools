=====================================
Auth Signup: Parent Company Selection
=====================================

* Allows the user to select their parent partner when they signup
* You can define for each industry whether that industry's partners
  can be selected in the signup form 

Configuration
=============
* Configure the industries via Contacts -> Settings -> Industries

Usage
=====
* Register as a new user to see the new dropdown selection field

Known issues / Roadmap
======================
* Note that when registration is allowed for the users to do themselves, 
  the companies will be shown to anyone who opens the signup form, 
  so the module is not recommended for situations where that 
  information should be kept private.
* The selection a user makes is not automatically validated in any way,
  so the system is very much trust-based and backend users will need to 
  make corrections if wrong selections are made.
