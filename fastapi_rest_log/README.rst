================
Fastapi rest log
================
Fastapi rest log stores FastAPI call logs into Odoo (model ``fastapi.rest.log``).

Configuration
=============
No configuration required. Installing the module adds a menu entry **FastAPI REST Logs**
and the model ``fastapi.rest.log`` with fields: method, path, payload, response, status_code, odoo_user_id.
